# Terminology

<p class="calm-lede">
Use a compact vocabulary for the scientific workflow, saved study state, selection operations, and calculated results.
</p>

## Purpose

This page defines the terms used repeatedly across the manual. The definitions describe the public user model. They do not expose CALM's storage schema or internal implementation classes.

## Canonical import or convention

Use these nouns consistently:

```text
project
material
surface
termination
search
candidate
interface
refinement
relaxation
raw energy
reference calculation
derived quantity
dataset
campaign
```

A normal workflow moves from user-authored inputs to saved results:

```text
material -> surface -> search -> candidate -> interface
         -> refinement -> relaxation -> energy/reference results
```

Datasets and campaigns are optional downstream study-management tools.

## Exact behavior

### Scientific structures and cells

**Basis** — An ordered set of vectors used to represent a lattice. Different unimodular bases can represent the same lattice.

**Lattice** — The infinite set of integer translations generated by a basis.

**Material** — A saved periodic bulk structure used as a source for surfaces or calculator-backed preparation. A material may be imported or produced by an optimization workflow.

**Miller index** — An integer reciprocal-lattice triplet `(h, k, l)` selecting a family of crystal planes. It does not uniquely determine an atomistic surface termination.

**Surface** — A finite, oriented slab model derived from one material, one Miller orientation, one thickness choice, vacuum, and an ordered termination pair.

**Termination** — The periodic atomic motif exposed at a slab boundary. CALM distinguishes the ordered top and bottom faces of a surface.

**Surface cell** — The two-dimensional periodic repeat in the selected plane.

**Supercell** — A larger periodic repeat produced by an integer map of a parent cell. Its index gives the area multiplicity for a two-dimensional surface lattice.

**Coherent interface** — A periodic interface in which both sides share one in-plane repeat cell. The model excludes misfit dislocations within that chosen cell.

### Search, selection, and construction

**Search** — One saved bounded calculation that compares two exact surfaces under declared supercell, strain, size, and candidate limits.

**Candidate** — One feasible crystallographic match admitted by a search. A candidate describes compatible surface supercells and mismatch measures; it is not yet an atomistic interface.

**Pareto candidate** — A candidate not dominated in the declared size–mismatch objective space. Pareto membership removes clearly inferior tradeoffs but does not identify one universally best interface.

**Geometric score** — A deterministic ranking of geometric candidate fields. It is not a total energy, stability measure, or experimental probability.

**Interface** — An atomistic model built from a candidate, explicit contact faces, a common cell, strain partition, registry, gap, and boundary settings.

**Built interface** — A constructed and saved interface before calculator-backed structural relaxation. It may already include selected strain partition and registry choices.

**Refinement** — A bounded exploration of strain partition, registry, or another declared construction variable. Refinement changes the model according to explicit settings; it is distinct from atomic relaxation.

**Strain partition** — The rule assigning the coherent mismatch between the two sides. CALM uses the coordinate `alpha` on a metric path between the candidate cells.

**Registry** — The relative in-plane translation of the two contact motifs, represented periodically in fractional coordinates of the common cell.

### Calculations and thermodynamic interpretation

**Calculator** — An ASE-compatible energy/force backend created from a reconstructible CALM `Potential` specification.

**Provider family** — The registered adapter family used to construct a calculator, such as `ase`, `mace`, or `lammps`.

**Model** — The exact calculator or potential selection within one provider family. A registered model name is not evidence of scientific suitability.

**Relaxation** — A local optimizer workflow that changes atomic positions and, only when explicitly enabled, cell degrees of freedom until a stopping condition or failure occurs.

**Converged** — The reported terminal state satisfies the declared numerical convergence condition. Convergence does not prove global stability.

**Raw energy** — A calculator total energy in eV for one exact structure, calculator identity, and calculation protocol.

**Reference calculation** — A bulk or isolated-surface calculation used by one explicit thermodynamic convention.

**Energy convention** — The formula, area source, interface multiplicity, and reference process used to derive an interfacial quantity.

**Derived quantity** — An interfacial excess energy, work of separation, or work of adhesion formed from compatible raw and reference energies. It is not available when required evidence is missing or incompatible.

### Projects, identifiers, and lineage

**Project** — A reopenable CALM study containing saved workflow inputs, results, relationships, and user-facing artifacts.

**Name** — A user-assigned label intended to communicate scientific meaning. A name is convenient but may be ambiguous across object types or contexts.

**Short identifier (`id_short`)** — A compact stable selector useful in tables and interactive work.

**Full identifier (`uid_full`)** — The complete stable identifier for one exact saved object and its defining inputs.

**Lineage** — The recorded parent–child relationships connecting source objects and derived results.

**Artifact** — A file or exported data object associated with a public workflow result, such as a structure, table, trajectory, or manifest.

**Collection** — A public group of objects returned by a project query. Collections support filtering, exact selection, and table views.

**View** — A named selection and ordering of public table fields intended for one inspection task. A table view does not define object identity.

### Datasets and campaigns

**Dataset** — A declared collection of eligible source results with explicit features, targets, grouping, split policy, validation, and export behavior.

**Grouping key** — A value used to keep scientifically related rows in the same dataset partition and prevent leakage.

**Campaign** — A declared grid or list of comparable cases executed through selected workflow stages.

**Case** — One exact campaign configuration. Cases should be compared only when their reported quantities and scientific conventions are compatible.

### Terms deliberately avoided in the user manual

The public documentation does not require users to reason about internal storage formats or implementation machinery. When exact reproducibility matters, use public names, identifiers, settings, lineage, manifests, and exported artifacts.
