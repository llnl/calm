# Archived documentation-support notes

This directory retains implementation and qualification notes for provenance.
They are intentionally excluded from both the public MkDocs site and the live
executable engineering tree.

The public scientific explanations live under `docs/scientific-background/`.
They describe the quantities users need to choose settings and interpret
results. The archived notes here preserve exact canonicalization, certificate,
numerical-control, external-library-boundary, and failure-boundary details from
the documentation redesign.

These files are not live maintainer instructions or a parallel user manual.
Do not link them from the public navigation or treat them as current contracts
without checking the implementation and tests.
