# Calculators tutorial (overview)

This tutorial is a short overview showing how to pick a calculator family and
build a simple calculator via the `calm.calculators` utilities. The registry
exposes first-class families such as `ase`, `chgnet`, `grace`, `lammps`, and
`mace` which are registered by default. Other frameworks (for example,
`orb`, `m3gnet`, `matgl`, `nequip`, `sevennet`, `mattersim`) are considered
deferred/environment-only and are documented in the support matrix and
environment recipes.

Use the tutorial to learn how to select a family and call `calm.calculators.make_calculator`.
See docs/reference/calculator_provider_support.md for installation notes and
docs/getting-started/conda_environments.md for environment recipes.
