# Conda environment recipes (minimal)

This document lists example Conda environment recipes for optional calculator
providers and other heavy optional dependencies. Use these as starting points
when preparing environment-only installations for MLIP providers.

First-class families and their environment/install notes: `ase` (base / included),
`chgnet` (optional), `grace` (optional), `mace` (optional), `lammps` (engine-level).

Deferred frameworks / environment-only providers: `orb`, `m3gnet`, `matgl`, `nequip`, `sevennet`, `mattersim`.
