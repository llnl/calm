# Coordinate systems

CALM uses Cartesian and fractional-coordinate representations of crystalline objects. Mathematical specifications should identify which coordinate system is used for each object, matrix, vector, and distance.

## Fractional to Cartesian mapping

For a cell matrix whose columns are lattice vectors, a fractional coordinate vector maps to Cartesian space by multiplication with the cell matrix. Representation changes of this type preserve scientific identity when the underlying structure and basis equivalence are unchanged.

## Surface and slab coordinates

Surface and slab specifications should distinguish in-plane coordinates, out-of-plane coordinates, embedded Cartesian vectors, and any canonical gauge used for comparison or persistence.
