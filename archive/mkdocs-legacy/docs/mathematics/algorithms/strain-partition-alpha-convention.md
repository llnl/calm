# Strain partition alpha convention

Short, normative statement of the alpha endpoint semantics for the geodesic strain partition helper.

- `alpha=0`: target metric is slab A; slab A is unstrained and slab B is deformed to A.
- `alpha=1`: target metric is slab B; slab B is unstrained and slab A is deformed to B.
- `alpha=0.5`: affine-invariant geodesic midpoint.

This document exists to provide a tiny, link-friendly reference for tests and cross-references.
