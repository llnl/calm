# Engineering Archive

CALM keeps internal engineering notes, design rationale, historical audits,
roadmaps, continuation records, and implementation handoff material in the
top-level `engineering/` directory.

That material is useful for maintainers, but it is not the primary source of
truth for current user-facing behavior and is intentionally not included in
the main public navigation.

For current user documentation, use the pages under `docs/`.

For current public API behavior, see:

- [`Public API`](../reference/public_api.md)
- `public_api.md`

For current workspace persistence behavior, see:

- [`Workspace Database Schema`](../reference/workspace_database_schema.md)
- `calm/project/infrastructure/db/tables.py`

For contributor-facing guidance and developer docs, use the Development section
of this site.

Historical engineering records may contain obsolete names, old database
layouts, superseded public API proposals, or completed migration plans. Treat
them as project history and consult them only when investigating design
decisions or migration provenance.
