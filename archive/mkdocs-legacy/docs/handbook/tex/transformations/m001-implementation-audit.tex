\subsection{Verification Obligations}

The implementation should establish:

\begin{enumerate}
\item $\det(S)=1$.
\item $\mathbf hS=(0,0,1)$.
\item The first two columns span $\ker(\mathbf h)\cap\mathbb Z^3$.
\item $S^{-1}\in SL(3,\mathbb Z)$.
\end{enumerate}

\subsection{Audit Findings}

The implementation is more accurately described as a constructive
unimodular reduction using successive Bézout eliminations than as a
general Hermite Normal Form computation. This terminology should be
used consistently throughout the handbook.
