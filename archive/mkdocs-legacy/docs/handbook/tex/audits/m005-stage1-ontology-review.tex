\chapter{M005 --- Slab Construction}

\section{Ontology Review}

\subsection{Purpose}

Review whether ``Slab'' is the immediate scientific object produced by
the implementation or whether intermediate scientific objects should be
recognized before continuing the audit.

\subsection{Motivation}

The M003 audit demonstrated that implementation structure can reveal a
scientifically meaningful decomposition not apparent in the initial
ontology. This review performs the same check for slab construction.

\subsection{Questions}

\begin{enumerate}
\item Is slab construction a single scientific transformation?
\item Are finite motif realization and slab geometry distinct objects?
\item Which parameters define the scientific object versus its
representation?
\end{enumerate}

\subsection{Working Hypotheses}

Candidate decompositions include:

\begin{itemize}
\item Surface Termination $\rightarrow$ Slab
\item Surface Termination $\rightarrow$ Finite Periodic Motif
      $\rightarrow$ Slab
\item Surface Termination $\rightarrow$ Slab Geometry
      $\rightarrow$ Canonical Slab
\end{itemize}

\subsection{Outcome}

The implementation review in Stage~3 will determine whether the current
ontology should be refined before the remainder of the M005 audit
proceeds.
