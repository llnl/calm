\chapter{M004 --- Surface Termination Selection}

\section{Stage 4 --- Comparison (Phase 2)}

\subsection{Mathematical Proposition}

Application of an admissible selection criterion to a finite Termination
Set yields a single Surface Termination together with a reproducible
selection decision.

\subsection{Implementation}

The implementation applies the configured selection policy after
evaluation of admissibility and before provenance recording.

\subsection{Comparison}

The implementation is consistent with the mathematical specification in
treating selection as a decision transformation rather than a
constructive transformation.

\subsection{Evidence}

Evidence includes the Stage 2 specification, Stage 3 implementation
review, and the documented implementation workflow.

\subsection{Audit Result}

No discrepancy has been identified for the selection phase.

\subsection{Outstanding Questions}

Stage 5 should verify determinism, configurability, and reproducibility
of the implemented selection policy.
