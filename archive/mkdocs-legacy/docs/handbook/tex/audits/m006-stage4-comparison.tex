implementation review (Stage~3). It records agreements, discrepancies, and
observations without proposing implementation changes.

\section{Summary}

At this stage, the comparison records the degree of agreement between the
mathematical specification and the implementation. Corrective actions, if
necessary, are deferred to later stages after supporting evidence has been
assembled.
