\chapter{M006 --- Finite Slab Geometry}

\section{Stage 1 --- Mathematical Specification}

\subsection{Scientific Purpose}

Realize a finite slab geometry from a Slab Specification.

\subsection{Transformation}

\[
\Phi_{\mathrm{geometry}}:
\mathcal{S}_{\mathrm{spec}}
\rightarrow
\mathcal{G}_{\mathrm{slab}}
\]

\subsection{Inputs}

\begin{itemize}
\item Slab Specification
\end{itemize}

\subsection{Output}

Finite Slab Geometry.

\subsection{Preconditions}

Valid Slab Specification.

\subsection{Postconditions}

Finite atomic geometry realizing the specification.

\subsection{Invariants}

\begin{itemize}
\item Slab specification
\item Surface termination
\item Crystallographic orientation
\end{itemize}

\subsection{Gauge Freedoms}

Equivalent origin choices and cell translations preserving the realized
geometry.
