\chapter{M004 --- Surface Termination Selection}

\section{Stage 3 --- Implementation Decomposition}

\subsection{Purpose}

Identify the implementation phases used to select a single surface
termination from an enumerated termination set.

\subsection{Implementation Phases}

\begin{enumerate}
\item Receive a finite termination set.
\item Apply a selection policy.
\item Validate the selected termination.
\item Attach provenance to the selected object.
\end{enumerate}

\subsection{Phase Classification}

\begin{tabular}{ll}
Selection policy & Scientific transformation\\
Validation & Scientific verification\\
Provenance attachment & Representation transformation\\
\end{tabular}

\subsection{Stage Status}

This document records the implementation decomposition only. No
correctness assessment is performed.
