\section{Stage 4 --- Comparison (Phase 3)}

Given a primitive Miller covector, the construction shall produce a
primitive integer kernel basis together with a Bézout witness that
certifies the kernel construction.

\subsection{Implementation Observation}

primitive kernel/Bézout triplet $(u,v,w)$ and uses this certificate in
later reduction stages.

\subsection{Comparison}

The implementation contract matches the mathematical specification
developed during Stages 1 and 2.

The certificate-based formulation is stronger than merely producing
kernel vectors because it explicitly records the Bézout witness.

\subsection{Evidence}

\item Stage 3 implementation decomposition.
\item Module algorithm documentation.
\end{itemize}

No discrepancy has been identified.

operation preserves the primitive-kernel certificate.
