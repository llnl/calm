\chapter{M004 --- Surface Termination Selection}

\section{Stage 2 --- Mathematical Analysis}

\subsection{Objective}

Establish the mathematical properties of selecting a single surface
termination from a finite Termination Set.

\subsection{Definition}

A selection criterion is a deterministic or explicitly specified rule
that maps a non-empty Termination Set to one of its members.

\subsection{Proposition M004.1}

Given a non-empty finite Termination Set and an admissible selection
criterion, there exists a unique selected Surface Termination.

\subsection{Proof Strategy}

The proof will establish:

\begin{enumerate}
\item The Termination Set is finite (M003).
\item The selection criterion is total on admissible inputs.
\item The selected termination belongs to the input Termination Set.
\item Provenance records the criterion used.
\end{enumerate}

\subsection{Open Mathematical Questions}

\begin{itemize}
\item Deterministic versus user-driven selection.
\item Preference ordering among admissible terminations.
\item Selection under symmetry-equivalent alternatives.
\end{itemize}
