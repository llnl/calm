
\chapter{M002 --- Primitive Surface Construction}

\section{Stage 3 --- Implementation Decomposition}

\subsection{Purpose}

This stage records the mathematical decomposition expressed by the
implementation. No correctness assessment is performed.

\subsection{Implementation Phases}

The implementation documents the following sequence of transformations.

\begin{enumerate}
\item Rationalize and verify the conventional-to-primitive basis transform.
\item Transform conventional Miller indices into a primitive Miller covector.
\item Construct an exact primitive kernel/B\'ezout triplet $(u,v,w)$.
\item Optionally Gauss-reduce the in-plane basis while preserving the
primitive-kernel certificate.
\item Minimize stacking-vector shear while preserving the B\'ezout
constraint.
\end{enumerate}
