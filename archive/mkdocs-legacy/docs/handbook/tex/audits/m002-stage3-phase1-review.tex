
\chapter{M002 --- Primitive Surface Construction}

\section{Stage 3 --- Implementation Review (Phase 1)}

\subsection{Reviewed Transformation}

Rationalize and verify the conventional-to-primitive basis transform.

\subsection{Mathematical Input}

A conventional crystallographic basis together with a candidate
conventional-to-primitive basis transformation.

\subsection{Mathematical Output}

A verified primitive basis transformation suitable for subsequent
construction of a primitive surface.

\subsection{Algorithmic Role}

This phase establishes the lattice basis in which all subsequent
operations are performed. It is therefore a prerequisite for the Miller
covector transformation and the primitive kernel construction.

\subsection{Classification}

\begin{itemize}
\item Scientific transformation.
\item No gauge operation identified.
\item No representation projection identified.
\end{itemize}

\subsection{Open Questions for Stage 4}

\begin{enumerate}
\item Is the verification mathematically sufficient?
\item Does rationalization preserve all required lattice invariants?
\item Are all admissible primitive bases accepted?
\end{enumerate}
