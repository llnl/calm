# CALM Mathematical Handbook

This handbook accompanies the engineering mathematical specifications. Each
transformation is documented as a mathematical monograph linked to its
implementation and verification.

## Purpose

The Handbook collects detailed monographs and audit summaries that provide
long-form background and verification evidence for the mathematical
specifications found under `docs/mathematics/algorithms/`.

This content is primarily intended for advanced readers and reviewers. Short
audit summaries and a navigation pointer are surfaced in the main documentation
site; full TeX monographs remain in `docs/handbook/tex/` and are linked from
this landing page. If you need a human-friendly summary, check the audit
summary pages listed below.
