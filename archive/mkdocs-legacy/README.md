# Legacy MkDocs Documentation

This directory contains previous MkDocs-facing CALM documentation retained for
provenance and reference.

These files are not current user documentation. They may contain obsolete public
API names, old workspace layouts, stale example references, historical database
concepts, and superseded workflow descriptions.

For current documentation, use `docs/`.

For current behavior, use the implementation under `calm/`, tests under
`tests/`, current `examples/*.py`, and the public API contract in `public_api.md`.
